# Viewing an entry's change history

Every test in the catalogue keeps a record of the changes made to it. This page explains how
to open that record and how to read it. Anyone can read it, signed in or not.

## Open the history

1. Open the test's page, for example `/catalogue/NPTC-000247`. See
   [Reading an entry](reading-an-entry.md).
2. In **Recent changes**, choose **View full history**.

The history has its own address, `/catalogue/NPTC-000247/history`. You can bookmark it or
send it to someone. The breadcrumb at the top links back to the test.

## Read a change

The newest change comes first. Each change shows:

- **The time**, in Australian Eastern Standard Time (UTC+10) whatever your own time zone is.
- **Who made it**, as "By" and a name. The name appears only when you are signed in. If you
  are signed out, or the change was made by the system or by an account since closed, the
  line is left out. The page does not say which of these applies.
- **What happened**, such as "Designation created".
- **Fields**, the names of the fields the change touched. The page shows the names only, not
  the old or new values.
- **Reason**, the note the editor wrote with the change, if any.

The history does not yet show which release a change went into. Releases come in a later
phase.

## Move through a long history

The page shows fifty changes at a time. Below the list:

- Choose **Next page** to see older changes.
- Choose **Previous page** to go back. It is unavailable on the first page you opened.
- **No more results** means you have reached the oldest change.

The address changes with each page, so a link to page two opens page two. If you open a
link in the middle of a history, **Previous page** can only return you to the pages you
visited from there. To start again, open the history from the test's page.

You can use the keyboard throughout. Tab to a button and press Enter. Focus stays on the
button you chose while the next page loads.

## If something goes wrong

- **No changes are recorded for this entry.** The test has no history to show.
- **The change history could not be loaded.** The page offers **Try again**.
- **The change history could not be refreshed just now.** The page keeps the changes already
  on screen and warns you they may be out of date.
- **We couldn't find that page.** No test has that identifier, the test is not published, or
  the link's page marker is not valid. The page does not say which. Choose **Search the
  catalogue** to find the test by name or code.
